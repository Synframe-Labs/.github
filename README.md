# synframe

Shared contribution guidelines and templates for the "synframe" GitHub organization.

- [Organization profile](profile/README.md)
- [Contribution guidelines](CONTRIBUTING.md)
- [Security reporting](SECURITY.md)

Repository-specific guidelines take precedence over these defaults. Access to private repositories does not grant permission to redistribute their contents. Public projects define their terms in their own licenses.

Visit [synframe.eu](https://synframe.eu/) to learn about our services and get in touch.
